Condiciones: if, elif, else

  • if condición: ejecuta las líneas de dentro (con sangría) solo si la condición es verdadera.
  • elif = «si no, pero si…». else = «en cualquier otro caso».
  • Se ejecuta solo la primera rama cuya condición se cumpla; las demás se saltan.
  • Comparar: == igual, != distinto, < > <= >=. Combinar: and, or, not.
if dinero >= precio:
	print("Compras la semilla")
else:
	print("No te llega el dinero")

🏪 Reto: la tienda decide

Une cada operador con su significado:

  • ==¿Son iguales?
  • !=¿Son distintos?
  • >=¿Es mayor o igual?
  • andSe cumplen las dos
  • orSe cumple al menos una
  • notLo contrario

Con energia = 30, ¿qué se imprime?

if energia > 50:
	print("A tope")
elif energia > 20:
	print("Cansado")
else:
	print("Agotado")

30 no es mayor que 50, así que se salta la primera rama. 30 sí es mayor que 20: «Cansado».

Mismo código, ahora con energia = 80. ¿Qué se imprime?

80 cumple las dos condiciones, pero solo se ejecuta la primera rama verdadera. Por eso el orden de las condiciones importa.

Solo puedes bajar a la mina si tienes pico y no es de noche. ¿Qué condición es?

Hacen falta las dos cosas (and): tener pico, y que no sea de noche (not).

Este código no funciona. Toca la línea culpable:

Un solo = guarda un valor; dos == comparan. Dentro de un if casi siempre quieres ==.
