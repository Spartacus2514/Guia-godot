Estructura de un script

Orden habitual

extends Node3D                     # qué tipo de nodo amplía

signal cultivo_listo(nombre: String)   # señales
const PRECIO = 20                  # constantes
@export var velocidad: float = 5.0 # variables del Inspector
var dinero: int = 500              # variables normales


func _ready():                     # una vez, al empezar
	pass


func _process(delta):              # cada fotograma
	pass

Fuera de las funciones solo hay declaraciones. Las instrucciones (como print) van dentro de una función. pass = «no hagas nada» (para bloques vacíos).

Variables y tipos

Declarar variables y constantes

var dinero: int = 500       # entero
var energia: float = 99.5   # decimal
var lloviendo: bool = false # true / false
var nombre: String = "Ana"  # texto
var vidas := 3              # := deduce el tipo (int)
const MAX_ENERGIA = 100     # nunca cambia
@export var velocidad := 5.0 # editable en el Inspector

Operaciones

dinero += 50     # dinero = dinero + 50   (también -=, *=, /=)
7 / 2            # 3   (entero / entero = entero)
7 / 2.0          # 3.5
7 % 2            # 1   (resto de la división)
str(dinero)      # el número convertido en texto: "550"
"Hola " + nombre # unir textos
print("Dinero: ", dinero)  # print une varias cosas separadas por comas

Condiciones

if, elif, else

if energia <= 0:
	print("Te desmayas")
elif energia < 30:
	print("Estás cansado")
else:
	print("Tienes energía")

Solo se ejecuta la primera rama que se cumple.

Comparar y combinar

a == b   # iguales          a != b   # distintos
a < b    a > b    a <= b    a >= b
tiene_pico and not es_de_noche   # and: las dos · or: al menos una · not: lo contrario
if "nabo" in inventario:         # ¿está dentro?

Funciones

Definir y llamar

func gastar_energia(cantidad: int = 5) -> void:  # = 5: valor por defecto
	energia -= cantidad

func puede_comprar(precio: int) -> bool:  # devuelve un bool
	return dinero >= precio

gastar_energia(10)   # llamar con un dato
gastar_energia()     # usa el valor por defecto (5)
if puede_comprar(20):
	print("¡A comprar!")

Las variables creadas dentro de una función son locales: solo existen ahí. return devuelve un valor y termina la función.

Arrays (listas)

Crear y usar

var cultivos: Array[String] = ["nabo", "patata"]
cultivos[0]              # "nabo" (se empieza en 0)
cultivos[-1]             # el último
cultivos.append("fresa") # añadir al final
cultivos.size()          # cuántos hay
cultivos.has("nabo")     # ¿está? → true / false
cultivos.erase("nabo")   # quitar por valor
cultivos.remove_at(0)    # quitar por posición
cultivos.clear()         # vaciar
cultivos.is_empty()      # ¿está vacío?

Bucles

for y range

for cultivo in cultivos:   # una vuelta por elemento
	print(cultivo)

for i in range(5):         # 0, 1, 2, 3, 4
	pass
for i in range(1, 8):      # 1 … 7 (el final no se incluye)
	pass
for i in range(10, 0, -2): # 10, 8, 6, 4, 2
	pass

while, break y continue

while energia > 0:   # repite mientras se cumpla
	energia -= 10    # ¡algo debe hacer falsa la condición!

for cultivo in cultivos:
	if cultivo == "seco":
		continue     # salta a la siguiente vuelta
	if cultivo == "maleza":
		break        # sale del bucle
	print(cultivo)

Diccionarios

Crear y usar

var inventario: Dictionary = {"nabo": 3, "patata": 5}
inventario["nabo"]            # 3 (¡error si la clave no existe!)
inventario["fresa"] = 2       # añadir o cambiar
inventario.get("melon", 0)    # 0 si no existe (sin error)
inventario.has("nabo")        # ¿existe la clave?
inventario.erase("patata")    # quitar
inventario.keys()             # ["nabo", "fresa"]
inventario.values()           # [3, 2]

for objeto in inventario:     # recorre las CLAVES
	print(objeto, ": ", inventario[objeto])

# Sumar exista o no:
inventario["nabo"] = inventario.get("nabo", 0) + 1

Vector3

Posiciones y direcciones

position = Vector3(3, 0, -2)       # colocar (en metros)
position += Vector3(1, 0, 0)       # mover desde donde está
Vector3.ZERO      # (0, 0, 0)
Vector3.UP        # (0, 1, 0)   arriba es +Y
Vector3.FORWARD   # (0, 0, -1)  adelante es −Z
Vector3.RIGHT     # (1, 0, 0)

a.distance_to(b)          # metros entre a y b
(b - a).normalized()      # dirección de a hacia b (largo 1)
global_position           # posición en el mundo (position es relativa al padre)

Al imprimir un vector, Godot muestra los decimales: print(Vector3.FORWARD) escribe (0.0, 0.0, -1.0).

Nodos y señales

Acceder a otros nodos

$Timer                          # el hijo llamado "Timer"
$Huerto/Nabo                    # un nodo dentro de otro
@onready var reloj: Timer = $Timer  # guardarlo al empezar

El nombre tiene que coincidir exactamente con el del árbol, mayúsculas incluidas.

Señales

signal cultivo_listo(nombre: String)       # declarar
cultivo_listo.emit("nabo")                 # emitir
$Nabo.cultivo_listo.connect(_on_cultivo_listo)  # conectar (¡sin paréntesis!)

func _on_cultivo_listo(nombre: String):    # la función que responde
	print("¡Listo: ", nombre, "!")

Señales que ya traen los nodos: Timer.timeout, Button.pressed, Area3D.body_entered, AnimationPlayer.animation_finished. También se conectan desde la pestaña Nodo, junto al Inspector.

Controles (Input)

Acciones del Mapa de Entrada

Input.is_action_pressed("mover_adelante")        # mientras la mantienes
Input.is_action_just_pressed("interactuar")      # solo al pulsarla
Input.is_action_just_released("usar_herramienta")  # solo al soltarla

Se crean en Proyecto → Configuración del Proyecto → Mapa de Entrada: escribe el nombre en Añadir Nueva Acción → Añadir → + en su fila → pulsa la tecla → Aceptar. Una acción puede tener varias teclas y botones del mando.

Dirección de las teclas

var entrada := Input.get_vector("mover_izquierda", "mover_derecha", "mover_adelante", "mover_atras")
var giro := Input.get_axis("camara_izquierda", "camara_derecha")

get_vector devuelve un Vector2: x = −1 izquierda / +1 derecha, y = −1 adelante / +1 atrás. En diagonal, (0.707107, -0.707107): el largo nunca pasa de 1. get_axis es un solo eje: −1, 0 o +1. := deduce el tipo de la variable.

El personaje: CharacterBody3D

Caminar con gravedad

extends CharacterBody3D

@export var velocidad: float = 4.0

func _physics_process(delta: float) -> void:
	if not is_on_floor():
		velocity += get_gravity() * delta
	var entrada := Input.get_vector("mover_izquierda", "mover_derecha", "mover_adelante", "mover_atras")
	var direccion := Vector3(entrada.x, 0, entrada.y)
	velocity.x = direccion.x * velocidad
	velocity.z = direccion.z * velocidad
	move_and_slide()

velocity: metros por segundo. move_and_slide() mueve, se para al chocar y se desliza (sin nada dentro de los paréntesis y sin multiplicar por delta). Cambia solo la x y la z: la y es la gravedad. Va en _physics_process, que se ejecuta 60 veces por segundo.

Qué necesita para chocar

El personaje: una CollisionShape3D con una cápsula (Position Y = 1 para que los pies queden en el suelo). El suelo, las vallas y las casas: un StaticBody3D con su forma. Atajo: selecciona el MeshInstance3D → Malla → Crear Forma de Colisión… → Hijo de Cuerpo Estático. Con position += se atraviesa todo.

Cámara y giros

Cámara que sigue

Granjero (CharacterBody3D)
└─ BrazoCamara (SpringArm3D)   ← Position Y = 1.5 · Rotation X = -50 · Spring Length = 8
   └─ Camara (Camera3D)

El brazo es hijo del granjero, así que la cámara le sigue sola. Sale hacia atrás (+Z) y se encoge si algo se mete en medio. Gíralo en Y para dar vueltas alrededor: brazo.rotation.y += giro * 2.0 * delta.

Moverse según la cámara

var direccion := Vector3(entrada.x, 0, entrada.y).rotated(Vector3.UP, brazo.rotation.y)

Gira la dirección de las teclas lo mismo que el brazo: «adelante» siempre es hacia el fondo de la pantalla.

Girar el modelo hacia donde camina

if direccion != Vector3.ZERO:
	var angulo := atan2(direccion.x, direccion.z)
	modelo.rotation.y = lerp_angle(modelo.rotation.y, angulo, velocidad_giro * delta)

Gira solo el Modelo (si giras el Granjero, gira la cámara). Los .glb miran hacia +Z (Vector3.MODEL_FRONT); si el tuyo va de espaldas, usa atan2(-direccion.x, -direccion.z).

Ángulos e interpolación

En el código los ángulos van en radianes: PI ≈ 3.14 = 180°, PI / 2 = 90°. En el Inspector, en grados (rotation_degrees). lerp(0, 10, 0.5) = 5: un valor entre dos. x = lerp(x, objetivo, peso) en cada fotograma = acercarse suave. lerp_angle hace lo mismo con ángulos, por el camino corto.

Animaciones

Reproducir animaciones del modelo

@onready var animaciones: AnimationPlayer = $Modelo/AnimationPlayer

func animar(direccion: Vector3) -> void:
	if direccion != Vector3.ZERO:
		animaciones.play("caminar")
	else:
		animaciones.play("quieto")

Llamar a play con la animación que ya suena no la reinicia. Los nombres son exactos (mayúsculas incluidas): míralos con print(animaciones.get_animation_list()). play("caminar", 0.2) mezcla durante 0.2 s.

Animaciones en bucle

Doble clic en el .glb → Ajustes Avanzados de Importación → selecciona la animación → Loop Mode: Linear → Reimportar. En Blender: termina el nombre en -loop y Godot la importa ya en bucle.

Interactuar y grupos

Rayo hacia delante

rayo.target_position = mirando * 1.5     # 1.5 m hacia donde mira

func interactuar() -> void:
	if not rayo.is_colliding():
		return
	var objeto := rayo.get_collider()
	if objeto.has_method("interactuar"):
		objeto.interactuar()

El RayCast3D ignora a su padre (Exclude Parent). get_collider() devuelve el cuerpo tocado (StaticBody3D, CharacterBody3D…): el script con interactuar() va en ese cuerpo. Para zonas (entrar en la mina), mejor un Area3D con body_entered.

Grupos

objeto.is_in_group("vacas")                        # ¿tiene la etiqueta?
for vaca in get_tree().get_nodes_in_group("vacas"):  # todos los del grupo
	print(vaca.name)

Se añaden en la pestaña Nodo → Grupos: +, escribe el nombre y Crear (el nodo seleccionado entra en el grupo).

Escena y visor 3D

Ctrl+A añadir nodo hijo · Ctrl+D duplicar · Ctrl+S guardar · Ctrl+Z deshacer · F centrar en lo seleccionado · Q W E R seleccionar, mover, rotar, escalar · clic derecho + WASD volar.

Scripts y depurador

Ctrl+clic en una palabra: abrir su documentación · F9 poner o quitar un punto de ruptura · F10 avanzar una línea · F11 entrar en la función.

Errores frecuentes

Los mensajes salen en inglés. Estos son los de Godot 4.7, comprobados provocando cada error; en otras versiones el texto puede cambiar un poco, así que fíjate en las palabras clave. Haz clic en el error, en la Salida o en el Depurador, y Godot te lleva a la línea.

Expected indented block

Expected indented block after "if" block.

Después de una línea que acaba en : (if, for, func…) falta la sangría. Pon un tabulador al principio de las líneas de dentro.

Used space character for indentation

Used space character for indentation instead of tab as used before in the file.

Has mezclado tabuladores y espacios en la sangría (pasa mucho al copiar código). Usa solo tabuladores: el menú Editar del editor de scripts tiene una opción para convertir la sangría.

Expected ":"

Expected ":" after "if" condition.

Falta el : al final de un if, elif, else, for, while o func.

Assignment is not allowed inside an expression

Assignment is not allowed inside an expression.

Has puesto un solo = donde querías comparar: if dinero = 100:. Para comparar se usan dos: ==.

Unexpected identifier in class body

Unexpected identifier "print" in class body.

Hay una instrucción (como print) fuera de cualquier función. Fuera de las funciones solo van declaraciones: muévela dentro de _ready() o de otra función.

Not declared in the current scope

Identifier "cosecha" not declared in the current scope.

Esa variable no existe ahí: está mal escrita, o es local de otra función. Declárala arriba del script o pásala como parámetro.

Function not found

Function "gastar_enrgia()" not found in base self.

Llamas a una función que no existe: casi siempre es una falta de ortografía.

Invalid operands

Invalid operands 'String' and 'int' in operator '+'.

Intentas sumar texto y número. Usa str(numero) o separa con comas dentro de print.

Cannot assign … type

Cannot assign a value of type "String" as "int".

Metes un dato de un tipo en una variable de otro tipo (por ejemplo, texto en un int).

Node not found

Node not found: "Timer" (relative to "/root/Granja/Datos").

El $Nodo no existe con ese nombre o esa ruta. Compara con el árbol: las mayúsculas cuentan. El mensaje te dice desde qué nodo buscaba.

null value / Nil

Cannot call method 'start' on a null value.

Invalid call. Nonexistent function 'start' in base 'Nil'.

Cannot call method 'has_method' on a null value.

Estás usando algo vacío (null, que Godot también llama Nil). El primer mensaje sale si la variable tiene tipo (var reloj: Timer), y el segundo si no lo tiene. Casi siempre viene de un Node not found anterior, de una variable a la que nunca diste valor o de un get_collider() sin nada delante (comprueba antes is_colliding()). El error salta donde se usa, pero la causa suele estar antes.

Invalid access of index

Invalid access of index '3' on a base object of type: 'Array'.

Pides una posición del array que no existe («fuera de rango»). Con 3 elementos, los índices son 0, 1 y 2.

Invalid access to property or key

Invalid access to property or key 'melon' on a base object of type 'Dictionary'.

Lees una clave de diccionario (o una propiedad) que no existe. Revisa cómo está escrita, o usa get(clave, valor_por_defecto).

InputMap action doesn't exist

The InputMap action "mover_adelnte" doesn't exist. Did you mean "mover_adelante"?

Esa acción no está en el Mapa de Entrada: casi siempre, una falta de ortografía. El juego no se para, pero la acción nunca cuenta como pulsada.

"$" before "_ready()"

The default value uses "$" which won't return nodes in the scene tree before "_ready()" is called. Use the "@onready" annotation to solve this.

Falta @onready delante de una variable que usa $Nodo.

velocity / move_and_slide no existen

Identifier "velocity" not declared in the current scope.

Function "move_and_slide()" not found in base self.

El script no extiende CharacterBody3D (por ejemplo, pone extends Node3D).

Too many / too few arguments

Too many arguments for "move_and_slide()" call. Expected at most 0 but received 1.

Too few arguments for "get_vector()" call. Expected at least 4 but received 2.

Le pasas a una función más o menos datos de los que acepta. move_and_slide(velocity) es de Godot 3: en Godot 4 va vacío. get_vector necesita las cuatro acciones.

Vector2 en un Vector3

Value of type "Vector2" cannot be assigned to a variable of type "Vector3".

Por ejemplo, velocity = entrada * velocidad: get_vector da dos números y velocity necesita tres. Pásalo a 3D con Vector3(entrada.x, 0, entrada.y).

Cannot infer the type

Cannot infer the type of "objeto" variable because the value doesn't have a set type.

Usas := con algo cuyo tipo Godot no conoce (por ejemplo, de una variable sin tipo). Ponle tipo a la variable de origen (@onready var rayo: RayCast3D = …) o usa = en vez de :=.

Animation not found

Animation not found: "Caminar".

Esa animación no existe con ese nombre: las mayúsculas cuentan. Míralos con print(animaciones.get_animation_list()).
