Cuando algo falla

  • Los errores son normales: los profesionales también los tienen a diario. Lo que marca la diferencia es saber leerlos.
  • Sintaxis: Godot marca la línea en rojo mientras escribes y el juego no arranca.
  • Ejecución: el juego arranca, pero se para en una línea y el panel Depurador explica por qué.
  • Lógico: no sale ningún error, pero el juego hace otra cosa. Se investiga con print o con un punto de ruptura.

¿Qué tipo de error es cada situación?

  • Mientras escribes, Godot marca una línea en rojoDe sintaxis
  • El juego se para y te lleva a una línea con un mensajeDe ejecución
  • Todo funciona, pero los nabos se venden a 0 monedasLógico

Leer un mensaje de error

Salen en inglés, pero casi siempre basta con reconocer unas pocas palabras clave. Además, haciendo clic en el error, Godot te lleva a la línea.

  • not declared = «no declarado»: esa variable no existe aquí.
  • not found = «no encontrado»: no encuentra ese nodo o esa función.
  • null o Nil = «nulo, nada»: estás usando algo que está vacío.
  • index = «índice»: esa posición no existe en la lista (por ejemplo, Invalid access of index '3').
  • expected = «se esperaba»: falta algo, como un : o la sangría.
  • invalid operands = «operandos no válidos»: operación entre tipos que no encajan.

Une cada palabra clave con lo que te está diciendo:

  • not declaredEsa variable no existe aquí
  • not foundNo encuentra ese nodo o esa función
  • nullEstás usando algo vacío
  • indexEsa posición no existe en la lista
  • expectedFalta algo: un :, la sangría…
  • invalid operandsOperación entre tipos que no encajan

Caso de detective. Al pulsar F6, la Salida muestra esto:

E Node not found: "Timer" (relative to "/root/Granja/Datos").
E Cannot call method 'start' on a null value.

Así es el árbol de la escena:

Granja
└─ Datos
   └─ Temporizador (Timer)

Y este es el script de Datos. Toca la línea donde está la causa:

extends Node

@onready var reloj: Timer = $Timer

func _ready():
	reloj.start()
	print("Granja lista")

El juego se rompe en la línea 6, pero la causa está en la 3: el nodo se llama Temporizador, no Timer. Como no lo encuentra, reloj queda vacío (null), y al usarlo en la línea 6, falla. Moraleja: el primer error de la lista suele ser el que importa.

Errores lógicos: espiar con print

El nabo tarda 3 días en crecer, pero el día 3 no sale «¡Nabo listo!» y Godot no da ningún error. Hemos puesto un print espía para ver qué pasa:

var dias = 0

func _ready():
	for i in range(3):
		pasar_dia()

func pasar_dia():
	dias += 1
	print("Día ", dias, " · dias > 3 es ", dias > 3)
	if dias > 3:
		print("¡Nabo listo!")

¿Cómo arreglas la condición para que el nabo esté listo el día 3?

>= es «mayor o igual». Este error (pasarse o quedarse corto por uno) es tan común que tiene nombre en inglés: off by one. Cuando el error esté arreglado, quita el print espía.

El depurador: pausar el juego

Si llenar la Salida de print se te queda corto, usa un punto de ruptura: haz clic a la izquierda del número de línea (sale un punto rojo) o pulsa F9. Al llegar ahí, el juego se pausa y el panel Depurador te enseña qué vale cada variable. Con F10 avanzas línea a línea, y con F11 entras dentro de una función. Es el «paso a paso» de este curso, pero dentro de Godot.

Quieres ver cuánto vale energia justo antes de que el granjero se desmaye, sin llenar la Salida de mensajes. ¿Qué haces?

El juego se pausa justo ahí y ves todas las variables a la vez.

Ordena el método para arreglar cualquier error:

  • Leer el mensaje entero (sobre todo el primero)
  • Hacer clic en el error para ir a la línea
  • Mirar qué valen las variables (print o punto de ruptura)
  • Cambiar una sola cosa
  • Probar otra vez con F6
Cómo pedir ayuda (a Claude o en un foro) Copia el mensaje de error exacto (en el Depurador, clic derecho sobre el error para copiarlo), el script y una frase de qué esperabas y qué ha pasado. Con eso, la respuesta llega a la primera. La chuleta tiene los errores más frecuentes traducidos.
  • En datos_granja.gd, quita el tabulador de una línea de dentro de _ready(). Lee el error rojo, búscalo en la chuleta y arréglalo.
  • Añade $Reloj.start() al principio de _ready() y pulsa F6. Lee el Node not found y borra la línea.
  • Pon un punto de ruptura (F9) en la primera línea de gastar_energia. Pulsa F6, mira energia y cantidad en el Depurador y avanza con F10.
  • Quita el punto de ruptura y continúa el juego con el botón de continuar del Depurador.
