Funciones

  • Una función es un bloque de código con nombre que puedes ejecutar (llamar) las veces que quieras: gastar_energia(10).
  • Los parámetros son los datos que recibe, entre paréntesis.
  • return devuelve un resultado y termina la función.
  • Las variables creadas dentro de una función solo existen ahí (son locales).
var energia: int = 100
var dinero: int = 500


# No devuelve nada (-> void): solo hace algo.
func gastar_energia(cantidad: int) -> void:
	energia -= cantidad
	if energia < 0:
		energia = 0


# Devuelve un bool: responde a una pregunta.
func puede_comprar(precio: int) -> bool:
	return dinero >= precio

Mira cómo el programa salta a la función y vuelve:

var energia = 100

func _ready():
	gastar_energia(30)
	gastar_energia(50)
	print("Energía: ", energia)

func gastar_energia(cantidad):
	energia -= cantidad

Une cada parte de func puede_comprar(precio: int) -> bool: con lo que significa:

  • funcAquí empieza una función
  • puede_comprarEl nombre para llamarla
  • (precio: int)El dato que recibe
  • -> boolEl tipo de lo que devuelve

¿Qué imprime este código?

func doble(n: int) -> int:
	return n * 2

func _ready():
	print(doble(doble(3)))

Primero se calcula lo de dentro: doble(3) = 6. Luego doble(6) = 12.

¿Qué pasa con las líneas que hay debajo de un return que se ejecuta?

return sale de la función en ese momento. Es útil para cortar pronto: if not puede_comprar(precio): return.
