Examen del módulo 3

Nada nuevo: el granjero entero, mezclado. Si un reto se te atraganta, vuelve a su lección. Al acabar tendrás el primer gran hito de tu juego: un granjero que camina por tu granja.

El jugador mantiene pulsadas W y D. ¿Qué devuelve Input.get_vector("mover_izquierda", "mover_derecha", "mover_adelante", "mover_atras")?

Derecha es x positiva y adelante, y negativa. Y en diagonal el largo se recorta a 1, para no caminar más rápido.

Para dar de comer a la vaca al pulsar E una vez, ¿qué condición usas?

Solo es true en el instante de pulsar. Con is_action_pressed le darías de comer en cada fotograma mientras mantienes la tecla.

El granjero camina bien, pero si sale caminando de lo alto de una caja, se queda flotando en el aire. Toca la línea culpable:

func _physics_process(delta: float) -> void:
	if not is_on_floor():
		velocity += get_gravity() * delta
	var entrada := Input.get_vector("mover_izquierda", "mover_derecha", "mover_adelante", "mover_atras")
	var direccion := Vector3(entrada.x, 0, entrada.y)
	velocity = direccion * velocidad
	move_and_slide()

Como direccion.y es 0, esa línea borra en cada fotograma la caída que acaba de sumar la gravedad. Hay que cambiar solo velocity.x y velocity.z.

El modelo gira hacia donde caminas, pero la cámara también da vueltas y marea. Toca la línea culpable:

func girar_modelo(direccion: Vector3, delta: float) -> void:
	if direccion != Vector3.ZERO:
		var angulo := atan2(direccion.x, direccion.z)
		rotation.y = lerp_angle(rotation.y, angulo, velocidad_giro * delta)

rotation.y a secas es la del propio Granjero, y con él giran todos sus hijos, el brazo de la cámara incluido. Debe ser modelo.rotation.y.

¿Qué usas para cada cosa?

  • Que el granjero no atraviese las vallasCharacterBody3D + move_and_slide()
  • Que la cámara no se quede detrás de una paredSpringArm3D
  • Saber qué tiene delante el granjeroRayCast3D
  • Pasar de «quieto» a «caminar»AnimationPlayer
  • Cambiar de tecla sin tocar el códigoAcciones del Mapa de Entrada
  • Encontrar todas las vacas de la granjaUn grupo

Ordena lo que hace el granjero en cada fotograma para caminar (cada paso necesita el anterior):

  • Leer las teclas: var entrada := Input.get_vector(…)
  • Pasarlas a 3D según la cámara: var direccion := Vector3(entrada.x, 0, entrada.y).rotated(…)
  • Poner la velocidad: velocity.x = direccion.x * velocidad (y la z)
  • Moverse chocando: move_and_slide()

El modelo mira a 170° y quieres que gire suave hasta −170°. ¿Qué usas?

lerp_angle gira 20° por el camino corto. lerp daría casi una vuelta entera (340°), y la asignación directa giraría de golpe.

¿Qué pasa con var rayo: RayCast3D = $Interaccion, sin @onready?

@onready espera a que la escena esté lista para buscar el nodo. Godot incluso te lo sugiere en el mensaje de error.

Completa la interacción, sin que falle cuando no hay nada delante:

func interactuar() -> void:
	if not rayo.():
		return
	var objeto := rayo.()
	if objeto.("interactuar"):
		objeto.interactuar()

Tu granjero, completo

Así queda granjero.gd con todo el módulo. Compáralo con el tuyo: si cambiaste los nombres de las animaciones por los de tu modelo, déjalos.

extends CharacterBody3D

@export var velocidad: float = 4.0
@export var velocidad_giro: float = 10.0

var mirando := Vector3.BACK

@onready var modelo: Node3D = $Modelo
@onready var animaciones: AnimationPlayer = $Modelo/AnimationPlayer
@onready var brazo: SpringArm3D = $BrazoCamara
@onready var rayo: RayCast3D = $Interaccion


func _physics_process(delta: float) -> void:
	# Girar la cámara con Q y R.
	var giro := Input.get_axis("camara_izquierda", "camara_derecha")
	brazo.rotation.y += giro * 2.0 * delta

	# Gravedad.
	if not is_on_floor():
		velocity += get_gravity() * delta

	# Caminar según la cámara.
	var entrada := Input.get_vector("mover_izquierda", "mover_derecha", "mover_adelante", "mover_atras")
	var direccion := Vector3(entrada.x, 0, entrada.y).rotated(Vector3.UP, brazo.rotation.y)
	velocity.x = direccion.x * velocidad
	velocity.z = direccion.z * velocidad
	move_and_slide()

	girar_modelo(direccion, delta)
	animar(direccion)

	# Interactuar con lo que hay delante.
	if direccion != Vector3.ZERO:
		mirando = direccion
	rayo.target_position = mirando * 1.5
	if Input.is_action_just_pressed("interactuar"):
		interactuar()


func girar_modelo(direccion: Vector3, delta: float) -> void:
	if direccion != Vector3.ZERO:
		var angulo := atan2(direccion.x, direccion.z)
		modelo.rotation.y = lerp_angle(modelo.rotation.y, angulo, velocidad_giro * delta)


func animar(direccion: Vector3) -> void:
	if direccion != Vector3.ZERO:
		animaciones.play("caminar")
	else:
		animaciones.play("quieto")


func interactuar() -> void:
	if not rayo.is_colliding():
		return
	var objeto := rayo.get_collider()
	if objeto.has_method("interactuar"):
		objeto.interactuar()
