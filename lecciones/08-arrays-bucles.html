Arrays y bucles

  • Un array es una lista: ["nabo", "patata", "fresa"]. Cada elemento tiene una posición (índice) que empieza en 0.
  • for elemento in lista: repite el código una vez por cada elemento.
  • for i in range(5): repite 5 veces (con i = 0, 1, 2, 3, 4).
  • while condición: repite mientras se cumpla. break sale del bucle antes de tiempo.
var cultivos: Array[String] = ["nabo", "patata", "fresa"]

func _ready():
	print(cultivos[0])           # nabo (el primero es el 0)
	cultivos.append("maíz")      # añade al final
	print(cultivos.size())       # 4 elementos
	print(cultivos.has("fresa")) # true
	cultivos.erase("patata")     # quita "patata"

Riega todos los cultivos con un bucle for:

var cultivos = ["nabo", "patata", "fresa"]
var regados = 0

func _ready():
	for cultivo in cultivos:
		print("Riego: ", cultivo)
		regados += 1
	print("Regados: ", regados)

🔢 Reto: domina range()

for i in range(, , ):
	print(i)

range(inicio, fin, paso): empieza en inicio, avanza de paso en paso y para antes de llegar a fin.

Con var cultivos = ["nabo", "patata", "fresa"], ¿qué es cultivos[1]?

Se cuenta desde 0: [0] es «nabo», [1] es «patata». Truco: cultivos[-1] es siempre el último.

¿Qué imprime?

func _ready():
	var mochila = ["nabo"]
	mochila.append("fresa")
	mochila.append("maíz")
	print(mochila.size())

Empieza con 1 elemento y añades 2: size() devuelve 3.

Este código se rompe al ejecutarse. Toca la línea culpable:

var cultivos = ["nabo", "patata", "fresa"]

func _ready():
	print(cultivos[3])

Hay 3 elementos, con índices 0, 1 y 2. El índice 3 no existe («fuera de rango»). El último es cultivos[2] o cultivos[-1].

Cuidado con while Si la condición de un while nunca deja de cumplirse, el bucle no termina nunca y tu juego se congela. Asegúrate de que algo dentro del bucle acabe haciendo falsa la condición (por ejemplo, energia -= 10).
