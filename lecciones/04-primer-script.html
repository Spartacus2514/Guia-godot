Tu primer script en GDScript

Clic derecho en un nodo → Añadir script → Crear. Este script hace girar las aspas de un molino:

extends Node3D                 # este script amplía un Node3D

var velocidad = 1.5            # variable: cuánto gira por segundo

func _ready():                 # se ejecuta UNA vez al empezar
	print("¡El molino funciona!")  # escribe en el panel Salida

func _process(delta):          # se ejecuta en CADA fotograma
	rotation.z += velocidad * delta
  • Orden habitual: extends → variables → funciones.
  • Lo que va dentro de una función lleva sangría (tabulador).
  • _ready(): una vez. _process(delta): cada fotograma.
  • En 3D hay tres ejes: X (izquierda-derecha), Y (arriba-abajo) y Z (delante-detrás). Se miden en metros.

Quieres que una gallina salte. ¿Qué parte de su posición cambias?

En Godot el eje Y apunta hacia arriba. Truco: los colores del editor son X roja, Y verde, Z azul.

Ordena el script (pon _ready antes que _process):

  • print("¡Hola!")

  • rotation.z += velocidad * delta

Este script da error. Toca la línea culpable:

extends Node3D

var velocidad = 1.5

func _process(delta):
rotation.z += velocidad * delta

Falta la sangría. Sin el tabulador, la línea no pertenece a _process y Godot da error.

Quieres mostrar «¡Buenos días, granjero!» una sola vez al empezar. ¿Dónde pones el print()?

En _process se imprimiría unas 60 veces por segundo.

¿Por qué * delta?

delta = segundos desde el fotograma anterior. Multiplicar por él convierte «por fotograma» en «por segundo», así el juego va igual en cualquier ordenador. Compruébalo:
