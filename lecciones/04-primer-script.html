Tu primer script en GDScript

Clic derecho en un nodo → Añadir script → Crear. Este es un script completo:

extends Sprite2D            # este script amplía un Sprite2D

var velocidad = 200         # variable: píxeles por segundo

func _ready():              # se ejecuta UNA vez al empezar
	print("¡Hola, Godot!")  # escribe en el panel Salida

func _process(delta):       # se ejecuta en CADA fotograma
	position.x += velocidad * delta
  • Orden habitual: extends → variables → funciones.
  • Lo que va dentro de una función lleva sangría (tabulador).
  • _ready(): una vez. _process(delta): cada fotograma.

Ordena el script (pon _ready antes que _process):

  • extends Sprite2D
  • var velocidad = 200
  • func _ready():
  • print("¡Hola!")
  • func _process(delta):
  • position.x += velocidad * delta

Este script da error. Toca la línea culpable:

extends Sprite2D

var velocidad = 200

func _process(delta):
position.x += velocidad * delta

Falta la sangría. Sin el tabulador, la línea no pertenece a _process y Godot da error.

Quieres mostrar «Partida iniciada» una sola vez. ¿Dónde pones el print()?

En _process se imprimiría unas 60 veces por segundo.

¿Por qué * delta?

delta = segundos desde el fotograma anterior. Multiplicar por él convierte «por fotograma» en «por segundo», así el juego va igual en cualquier ordenador. Compruébalo:
