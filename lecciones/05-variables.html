Variables y tipos

  • Una variable es una caja con nombre que guarda un dato: tu dinero, tu energía, el nombre de la granja.
  • Se crea con var nombre = valor y se cambia con nombre = otro_valor.
  • Cada dato tiene un tipo: int (entero), float (decimal), bool (verdadero/falso), String (texto, entre comillas).
  • const = un valor que nunca cambia. @export = la variable aparece en el Inspector.
const PRECIO_NABO = 20                       # constante: nunca cambia
@export var nombre_granja: String = "Valle Verde"   # se edita en el Inspector
var dinero: int = 500                        # número entero
var energia: float = 100.0                   # número con decimales
var lloviendo: bool = false                  # true (sí) o false (no)

El : int después del nombre es el tipo. Es opcional, pero ponlo siempre: así Godot te avisa si te equivocas antes de ejecutar el juego.

var dinero = 500
var precio = 80

func _ready():
	dinero = dinero - precio
	dinero -= precio
	print("Te quedan ", dinero, " monedas")

Une cada valor con su tipo:

  • 500int (entero)
  • 3.5float (decimal)
  • truebool (sí/no)
  • "nabo"String (texto)

¿De qué tipo es "500", con comillas?

Las comillas lo convierten en texto. 500 es un número con el que puedes hacer cuentas; "500" es solo texto.

Repartes 7 zanahorias entre 2 vacas: var por_vaca = 7 / 2. ¿Cuánto vale por_vaca?

¡Trampa típica! Entero entre entero da entero: se pierden los decimales. Si quieres 3.5, escribe 7 / 2.0.

Este script da error al ejecutarse. Toca la línea culpable:

var dinero = 500

func _ready():
	print("Dinero: " + dinero)

No se puede sumar texto y número. Dos soluciones: print("Dinero: ", dinero) (con coma) o convertir el número en texto con "Dinero: " + str(dinero).

El precio de venta de un nabo es siempre 20 y nunca cambia durante el juego. ¿Cómo lo declaras?

Con const, si por error intentas cambiarlo, Godot te avisa. Las constantes se suelen escribir en MAYÚSCULAS.

Tu script de datos

A partir de ahora, cada lección añade algo a un mismo script con los datos de tu granja. Al final del módulo será la base de tu economía.

extends Node

const PRECIO_NABO = 20

@export var nombre_granja: String = "Valle Verde"

var dinero: int = 500
var energia: int = 100


func _ready():
	print("Bienvenido a ", nombre_granja)
	print("Dinero: ", dinero, " · Energía: ", energia)
  • En granja.tscn, añade un nodo Node (el más básico) como hijo de Granja y llámalo Datos.
  • Añádele un script y guárdalo como scripts/datos_granja.gd.
  • Escribe el script de arriba (escríbelo tú en vez de copiarlo: se aprende mucho más).
  • Pulsa F6 y busca los dos mensajes en la Salida.
  • Selecciona Datos, cambia Nombre Granja en el Inspector y vuelve a pulsar F6.
